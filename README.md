# Xanathar: a Halloween build diary

A roughly 24-inch-wide, front-half beholder prop for Halloween 2026. Built with existing workshop materials, printed facial forms, foam, and eventually a moving central eye.

**Deadline:** October 31, 2026 (America/Chicago).  
**Budget goal:** under $200 in new spending, including tax and shipping.  
**Minimum successful result:** a convincing stationary Xanathar at twilight.  
**Upgrade:** a moving central eye and carefully placed lighting.

## Current state — October 12, 2026

A [printable rib prototype with source and cutting templates](cad/ribs-v1/README.md) is available and geometrically checked. Two rib sets are confirmed printed; first assembly/splice fit passed. Initial foam drape over two arches showed no sag. Third was printing and fourth planned; later completion is unconfirmed. Installed frame/foam/coating-load tests remain pending.

Motor inventory is complete and all motors work per builder. EcoPower WP110T and Deegoo MG996R are eye candidates. A Mega 2560 R3 and WANPTEK DPS3010U supply are available. The [single-servo bench test](firmware/servo-bench-test/README.md) is ready for user compilation/upload; suitability and loaded motion results are pending. Eye blank purchase/measurements and finishing tests are still unconfirmed.

This repository is both the working record and the seed of a reproducible “now you can too” guide. Proposals are not tested instructions. Record failures, actual dimensions, receipts, print settings, and useful photos as we build.

## Scope

- Fixed front-half body, brow, cheeks, mouth, teeth, and posed eyestalks.
- One approximately 7.8-inch central eye, stationary first, motion optional.
- Existing wood/PVC for structure; 3D printing for useful curves and mechanical interfaces.
- Existing half-inch upholstery-like foam for covering and facial shaping.
- Rear concealment is handled separately; do not spend project time redesigning it.
- No moving jaw, blinking, animated tentacles, full sphere, or larger body in this version.

Future CAD, firmware, and build photos should be added only as actual work is created. This is an unofficial fan project.
